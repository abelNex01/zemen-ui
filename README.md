# ZemenPix

A high-performance, browser-based image optimization tool. ZemenPix allows you to compress, resize, and enhance images locally without ever uploading them to a server, ensuring maximum privacy and speed.

## Features

- **Local Processing**: All image operations happen in your browser using WebAssembly. Your data never leaves your device.
- **Smart Compression**: Advanced algorithms to reduce file size while maintaining visual fidelity.
- **AI Upscaling & Sharpening**: Built-in tools to improve image clarity and resolution.
- **Multilingual Support**: Fully localized in English and Amharic.
- **Modern UI**: Clean, responsive interface with dark mode support.

## Tech Stack

- **Framework**: React / Vite
- **Styling**: Tailwind CSS / Framer Motion
- **Image Logic**: browser-image-compression
- **Icons**: Lucide React
- **Icons**: Wouter (Routing)

## Development

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
